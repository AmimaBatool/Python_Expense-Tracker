**Title: Expense Tracker Application**

Expense Tracker Application is a simple command-line application developed by using Python. This program allows users to record, view, delete, update and manage their daily expenses. This project is about Data Accumulation and helps to build a practical beginner level application.

**Features:**
  1. Add a New Expense.
  2. Enter Expense details like name, date, category, amount and description.
  3. View all Expenses.
  4. Update an Expense, if needed.
  5. Calculate total spendings.
  6. Delete an Expense.
  7. Exit the application.
  8. Command-line Menu.

**How to Run:**
  1. Download the project file.
  2. Open the project file in your VS code or any other editor. Make sure that python is installed in your computer.
  3. Open the terminal in project folder.
  4. Run this command "python Expense_Tracker.py" and press enter. Or simply run and debug the project.
  5. Program will run.
  6. Follow the menu shown on the terminal.
